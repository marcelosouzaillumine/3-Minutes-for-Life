Versão 1.0 Agosto 2026 Confidencial — uso exclusivo do parceiro

1. Visão geral

A Partner API do 3 Minutes for Life oferece acesso programático somente leitura ao conteúdo de devocionais. Com ela é possível exibir o devocional do dia e acessar a biblioteca completa em português, inglês e espanhol.

A API é REST, retorna JSON e usa autenticação por API Key.

2. Autenticação

Envie a API Key no cabeçalho Authorization de toda requisição:

HTTP Header
Authorization: Bearer 3mfl_sua_chave_aqui
Não compartilhe a chave em código público, repositórios ou logs. Em caso de comprometimento, solicite revogação imediata.

3. Base URL

URL base
https://wacdwnlrwsbmuhwztwrz.supabase.co/functions/v1/partner-api

4. Endpoints

4.1 — Devocional do dia

GET /devotionals/today

Retorna o devocional publicado para a data atual (UTC).

Parâmetros

ParamPadrãoDescrição
langpt-BRIdioma: pt-BR, en, es

Exemplo

curl
curl "https://wacdwnlrwsbmuhwztwrz.supabase.co/functions/v1/partner-api/devotionals/today" \
  -H "Authorization: Bearer 3mfl_sua_chave"

4.2 — Biblioteca de devocionais

GET /devotionals

Lista os devocionais publicados com paginação, do mais recente ao mais antigo.

Parâmetros

ParamPadrãoDescrição
langpt-BRIdioma: pt-BR, en, es
page1Página (começa em 1)
limit20Itens por página — máx. 100
category—UUID da categoria para filtrar

Exemplo

curl
curl "https://wacdwnlrwsbmuhwztwrz.supabase.co/functions/v1/partner-api/devotionals?page=1&limit=10" \
  -H "Authorization: Bearer 3mfl_sua_chave"

4.3 — Devocional por ID

GET /devotionals/:id

Busca um devocional pelo UUID ou número sequencial (ex: 1, 31).

curl
curl "https://wacdwnlrwsbmuhwztwrz.supabase.co/functions/v1/partner-api/devotionals/1" \
  -H "Authorization: Bearer 3mfl_sua_chave"

6. Formato de resposta

Toda resposta segue o mesmo envelope:

JSON — sucesso
{
  "data": {
    "id": "uuid-do-devocional",
    "publication_date": "2026-08-27",
    "language": "pt-BR",
    "title": "Como atravessar uma crise financeira?",
    "principle_statement": "A escassez pode abalar...",
    "scripture_reference": "Mateus 6.25",
    "scripture_text": "Por isso, digo a vocês...",
    "reflection": "<p>Texto HTML...</p>",
    "practical_application": "<p>Texto de aplicação...</p>",
    "prayer": "<p>Texto da oração...</p>",
    "category": { "id": "uuid", "name": "Dinheiro" },
    "theme": null
  },
  "meta": { "date": "2026-08-27", "language": "pt-BR" },
  "error": null
}
Os campos reflection, practical_application e prayer podem conter HTML. Use innerHTML ou um sanitizador antes de renderizar.

Meta de paginação (apenas /devotionals)

JSON
"meta": {
  "language": "pt-BR",
  "page": 1,
  "limit": 20,
  "total": 31,
  "total_pages": 2,
  "has_next": true
}

8. Rate limiting

Limite padrão: 1.000 requisições por hora por chave. Ao exceder, a API retorna 429 RATE_LIMIT. O contador reinicia automaticamente após 60 minutos.

Para volumes maiores, entre em contato para ajuste do limite.
