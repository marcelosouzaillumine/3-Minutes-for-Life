API de Parceiros

3 Minutes for Life · acesso somente leitura aos devocionais publicados · v1

1. Visão geral

A API permite que aplicativos e sites parceiros exibam os devocionais do 3 Minutes for Life. Todas as chamadas são GET, retornam JSON (UTF-8) e exigem uma chave de API.

2. Autenticação

Envie a chave no header x-api-key em toda requisição:

x-api-key: 3mfl_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
  • A chave é fornecida pela equipe do 3 Minutes for Life e exibida uma única vez. Guarde-a em local seguro.
  • Use a chave apenas no servidor (backend). Não a inclua em apps mobile, JavaScript de navegador ou repositórios públicos.
  • Cada chave tem validade (data informada na entrega) e o escopo devotionals:read.
  • Se a chave vazar, avise-nos imediatamente: ela será revogada e uma nova será emitida.

3. Base URL

https://api.3minutesforlife.com

Todas as rotas começam com /partner.

4. Endpoints

4.1 — Devocional do dia

GET /partner/devotionals/today

Aceita ?lang=. Retorna o devocional cuja data de publicação é a data de hoje (UTC). Retorna 404 se não houver devocional para a data.

curl "https://api.3minutesforlife.com/partner/devotionals/today" \
  -H "x-api-key: SUA_CHAVE"

{

4.3 — Devocional por ID

GET /partner/devotionals/:id
curl "https://api.3minutesforlife.com/partner/devotionals/ID_DO_DEVOCIONAL" \
  -H "x-api-key: SUA_CHAVE"

Retorna 404 se o ID não existir.

5. Idiomas

O conteúdo original está em português do Brasil (pt-BR). Para receber outro idioma, use o parâmetro lang em qualquer endpoint:

curl "https://api.3minutesforlife.com/partner/devotionals/today?lang=en" \
  -H "x-api-key: SUA_CHAVE"
  • lang aceita códigos como en, es ou en-US (en-US usa a tradução en, e vice-versa).
  • Sem lang, ou com lang=pt-BR, a resposta vem em português.
  • Só traduções publicadas são entregues. Se o idioma pedido não estiver disponível, o conteúdo volta em português e o campo language mostra pt-BR. Confira sempre esse campo.
  • availableLanguages lista os idiomas disponíveis para aquele devocional.

Campos da resposta relacionados a idioma:

CampoDescrição
languageIdioma do conteúdo retornado
availableLanguagesIdiomas disponíveis para este devocional

8. Limite de requisições

O limite é de 120 requisições por minuto por IP. As respostas incluem x-ratelimit-limit, x-ratelimit-remaining e x-ratelimit-reset. Ao receber 429, aguarde o tempo indicado em retry-after.

Recomendação: guarde em cache o devocional do dia no seu servidor (ele muda uma vez por dia) em vez de consultar a API a cada acesso de usuário.
